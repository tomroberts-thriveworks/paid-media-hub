# paid-media-hub
Thriveworks paid media: API connections, reporting and (later) management.
Phase 1: Google Ads read-only reporting. Next: Microsoft Ads, Meta Ads.
Reporting rules: Bookings* = Event 1 + Event 4; CPB = spend / Bookings*; never
report a proxy-goaled campaign's own "conversions" as bookings. Aggregate ad data only, no PHI.
See SETUP.md.
